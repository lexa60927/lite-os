## LiteCraft — 3D-воксельная игра (браузер)

Песочница в духе Minecraft: бесконечный процедурный мир, копка и установка блоков,
деревья, руды, пещеры, вода, факелы, цикл дня и ночи, сохранение мира в браузере.
Всё на Three.js, без единого внешнего ассета — текстуры, звуки и музыка генерируются кодом.

### Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # прод-сборка в dist/
npm test           # смоук-тест всей игры в Node (физика, добыча, сохранение, UI)
npm run test:shaders
```

### Управление (клавиатура и мышь)

| Клавиша | Действие |
| --- | --- |
| W A S D / стрелки | движение |
| Shift | бег |
| Ctrl | красться |
| Пробел | прыжок, в воде — всплыть |
| ЛКМ (держать) | копать блок |
| ПКМ | поставить блок (колесо мыши — держать и ставить подряд) |
| колесо / 1…9 | выбор слота хотбара |
| Q | выбросить предмет из слота |
| E | инвентарь (креатив: все блоки) |
| F | вид от первого/третьего лица |
| G | креативный полёт (F + пробел/Shift — вверх/вниз) |
| T | время: держать = ускоренная смена суток |
| F3 | отладочная панель, F1 — скрыть интерфейс |
| Esc | пауза, ` — сид мира |

На телефоне появляется сенсорный джойстик и кнопки обзора/копки; настройка
`Сенсорное управление` в меню включает их принудительно.

### Что внутри

```
src/engine/    шум, блоки, генератор мира (биомы, пещеры, руды, деревья), мешинг чанков
src/render/    атлас пиксельных текстур, материал чанков (AO + свет + туман), небо, частицы, руки
src/game/      игрок и физика, рейкаст по вокселям, WebAudio-синтез, сохранения
src/ui/        HUD, инвентарь, меню, настройки, тач-управление
dev/           тесты и отладочные скрипты (смоук-тест гоняет игру на заглушках DOM)
```

Мир — чанки 16×16×128, правки хранятся как карта `x,y,z → id` и поверх генерации,
поэтому любой сид восстанавливается из `localStorage` целиком. Освещение — небо по
высоте + свет от факелов (BFS по 14 уровням), затенение граней и ambient occlusion
запекаются в вершины.
