# собранная игра

Это то, что кладёт `npm run build` (каталог `dist/`), — зафиксировано в репозитории,
чтобы игру можно было открыть ссылкой, не собирая ничего локально: статика отдаётся
как есть, без Jekyll (`.nojekyll`). Пути в сборке относительные (`base: './'` в
`vite.config.js`), поэтому каталог работает из любого поддомена и подпути.

Обновлять одной командой из корня репозитория:

```bash
npm ci && npm run build && rm -rf docs && cp -r dist docs && touch docs/.nojekyll
```

Двойным кликом по `index.html` из распакованного архива играть нельзя: браузер не
грузит ES-модули по `file://`. Нужен любой статический сервер, например
`python3 -m http.server 8080` в каталоге распаковки.
