Сетевая игра

Вдвоём без сервера (WebRTC)

Хост нажимает «Создать код» и отправляет получившуюся строку второму игроку так, как удобно (мессенджер, почта). Второй вставляет код, нажимает «Вставить и ответить» и возвращает код обратно. Дальше мир общий, сервер не нужен.

сеть выключена

Мир по сети не передаётся: он одинаковый у всех из сида, поэтому летают только позиция, правки блоков и чат. Своему реле: npm run net.
